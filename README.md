|---|---|

## TechClub Toolkit

Runs from a USB stick on Windows 11. Double-click `TechClub_Toolkit.bat`, approve the admin prompt, pick from the menu.

Suggested order for a visit: **Quick Check → Backup → Network Fix (if needed) → Auto-Fix**. Full details in [TechClub-Toolkit/README.txt](TechClub-Toolkit/README.txt).

Only run these on PCs you have permission to work on.
