# Glossary

| Term | Meaning |
|---|---|
| **AIO** | All-in-one liquid cooler: a sealed pump, radiator, and fans |
| **APU** | A CPU with built-in graphics (AMD's name) |
| **BIOS / UEFI** | Firmware that starts the PC before Windows loads. UEFI is the modern version |
| **Boost clock** | The highest speed a CPU core reaches briefly |
| **Bottleneck** | The slowest part that limits overall performance |
| **Cache** | Tiny, very fast memory inside the CPU |
| **CMOS battery** | Coin cell that keeps BIOS settings and the clock |
| **Core** | An independent processing unit inside a CPU |
| **DDR4 / DDR5** | Generations of RAM. Not interchangeable |
| **DIMM / SO-DIMM** | Desktop-size / laptop-size RAM stick |
| **Dedicated GPU** | A separate graphics card or chip with its own memory |
| **Driver** | Software that lets Windows control a piece of hardware |
| **ESD** | Electrostatic discharge: static that can damage parts |
| **Firmware** | Software stored on a hardware device itself |
| **Form factor** | The standard size and layout of a part (ATX, M.2, SO-DIMM) |
| **GPT / MBR** | Two ways to lay out partitions on a drive. GPT is the modern one |
| **GPU** | Graphics processing unit |
| **HDD** | Hard disk drive: spinning platters |
| **iGPU** | Integrated graphics built into the CPU |
| **M.2** | A small stick-shaped connector and form factor for drives and cards |
| **NVMe** | A fast protocol for SSDs over PCIe |
| **PCIe** | The fast expansion connection used by graphics cards and NVMe drives |
| **POST** | Power-on self-test run by the firmware at start-up |
| **PSU** | Power supply unit |
| **RAM** | Fast, temporary working memory |
| **SATA** | A connection standard for 2.5-inch drives, 3.5-inch drives, and some SSDs |
| **Secure Boot** | A UEFI feature that only lets trusted software start. Required by Windows 11 |
| **SMART** | A drive's built-in self-monitoring report |
| **Socket** | The connector for a CPU on the motherboard (for example, AM4, LGA1700) |
| **SSD** | Solid-state drive: flash memory, no moving parts |
| **TBW** | Terabytes written: an SSD's rated lifetime writes |
| **TDP** | Rated power and heat target for a chip, in watts. Not measured power use |
| **Thermal paste** | Compound that helps heat pass from chip to heatsink |
| **Thermal throttling** | The chip slowing itself down because it is too hot |
| **Thread** | An instruction stream a core handles. Often two per core |
| **TPM** | A security chip or firmware feature required by Windows 11 |
| **VRAM** | A graphics card's own memory |
| **VRM** | Voltage regulator module: converts the supply's voltage to what the CPU needs |
| **XMP / EXPO** | BIOS profiles that run RAM at its rated speed |
